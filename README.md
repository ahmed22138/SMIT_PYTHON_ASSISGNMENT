# SMIT_PYTHON_ASSISGNMENT

My Python assignments from SMIT. These are practice questions on Python data structures, 50 questions in total, split into 5 parts.

All the work is done in Jupyter notebooks (.ipynb). Each question has its own heading and the code is below it with the output.

## Rules we had to follow

- No for / while loops
- No list comprehensions
- No recursion
- No map, filter or reduce
- No hardcoded answers

So everything is solved using indexing, slicing, operators, built-in functions and the methods of list, tuple, set and dict.

### Assignment 1 - Lists
Accessing elements, slicing, modifying a list, reversing without reverse(), second largest number, rotating a list, removing duplicates, flattening a nested list, matrix diagonals and a small transformation challenge.

### Assignment 2 - Tuples
Indexing, unpacking, extended unpacking with `*`, concatenation, count and index, "changing" a tuple by making a new one, nested tuples, sorting by salary, a tuple matrix and an inventory question.

### Assignment 3 - Sets
Union, intersection, difference, symmetric difference, add / discard, subset and superset checks, finding missing numbers, and three-set questions (students, transactions, customers).

### Assignment 4 - Dictionaries
Accessing with get(), updating values, keys / values / items, pop(), merging dicts, student marks, nested employee records, inverting a dict, order total with discount, employee performance and inventory management.

### Assignment 5 - Mixed Data Structures
Questions where lists, tuples, sets and dicts are used together. Student performance, employee skills, sales, customer orders, course enrollment, e-commerce transactions, pipeline monitoring, banking, product recommendations and a final company analysis.

## How to run

Open the folder in VS Code (with the Python and Jupyter extensions) and open any `.ipynb` file. Then click "Run All".

Python 3 is needed.
